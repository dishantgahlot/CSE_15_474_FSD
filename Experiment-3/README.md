# Experiment 3 – Basic HTTP Server

## Aim

To create a basic HTTP server using Node.js.

## Objective

To understand how the Node.js `http` module can be used to create a web server and handle client requests.

## Technologies Used

* Node.js
* JavaScript
* HTTP module

## Main File

`exp3.js`

## Description

The program creates an HTTP server using:

```javascript
http.createServer()
```

The server responds to client requests and demonstrates HTTP response status and headers.

## How to Run

From the `JS` directory:

```bash
node Experiment-3/exp3.js
```

Open the server in a browser using the URL displayed by the program.

## Expected Result

The browser displays:

```text
Hello World
```

The server also demonstrates HTTP response headers and status code.

## Learning Outcome

This experiment demonstrates the basic working of an HTTP server and request-response communication in Node.js.
