# Experiment 2 – File System CRUD Operations

## Aim

To perform CRUD operations on files using the Node.js `fs` module.

## Objective

To understand how Node.js can create, read, update, and delete files.

## Technologies Used

* Node.js
* JavaScript
* File System (`fs`) module

## Main File

`exp2.js`

## Description

The experiment demonstrates file handling operations using the Node.js File System module.

The operations include:

* Creating a file
* Reading a file
* Updating file contents
* Deleting a file

## How to Run

From the `JS` directory:

```bash
node Experiment-2/exp2.js
```

## Expected Result

The program performs the requested file operations and displays the corresponding output.

## Learning Outcome

This experiment demonstrates basic file handling and CRUD operations using Node.js.
