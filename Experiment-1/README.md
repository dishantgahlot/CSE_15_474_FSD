# Experiment 1 – Node.js Events and Event Loop

## Aim

To understand event handling and the event loop mechanism in Node.js.

## Objective

To work with Node.js `EventEmitter`, event handling, and asynchronous execution.

## Technologies Used

* Node.js
* JavaScript
* EventEmitter

## Main File

`exp1.js`

## Description

This experiment demonstrates event-based programming in Node.js using events and event handlers.

It also covers asynchronous execution using mechanisms such as:

* `process.nextTick()`
* `setTimeout()`
* `setImmediate()`

## How to Run

From the `JS` directory:

```bash
node Experiment-1/exp1.js
```

## Expected Result

The program displays the output of registered events and demonstrates the execution order of asynchronous callbacks.

## Learning Outcome

This experiment helps understand event-driven programming and the Node.js event loop.
